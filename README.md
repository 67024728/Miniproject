# 📖 Easy Vocab - เรียนรู้คำศัพท์ให้เป็นเรื่องง่าย

**Easy Vocab** คือเว็บแอปพลิเคชันที่ออกแบบมาเพื่อช่วยให้การเรียนรู้และจดจำคำศัพท์ภาษาต่างประเทศเป็นเรื่องสนุก สะดวก และมีประสิทธิภาพ เหมาะสำหรับนักเรียน นักศึกษา หรือผู้ที่ต้องการพัฒนาทักษะทางภาษาด้วยตนเอง

---

## ✨ คุณสมบัติเด่น (Features)

* **Personal Vocabulary List:** สร้างและจัดการรายการคำศัพท์ส่วนตัวได้ตามต้องการ
* **Smart Categorization:** แยกหมวดหมู่คำศัพท์เพื่อให้ง่ายต่อการทบทวน
* **Interactive Learning:** โหมดช่วยจำที่ทำให้การท่องศัพท์ไม่น่าเบื่อ
* **User-Friendly Interface:** หน้าตาเว็บที่สะอาดตา ใช้งานง่าย ทั้งบนคอมพิวเตอร์และมือถือ
